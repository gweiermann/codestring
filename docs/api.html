API reference

Everything the packages export, grouped by what you reach for it. Types are elided where they only add noise; the shipped .d.ts files are the authority.

Creating a language

createLanguage(adapter, defaults?)

Binds an adapter to the parse entry point and the pattern tag. Call it once per adapter and reuse it.

const js = createLanguage(javascriptAdapter);
const ts = createLanguage(babelAdapter, { parseOptions: { plugins: ["typescript", "jsx"] } });

defaults takes parseOptions (passed straight to the adapter), trivia and onParseError. The returned Language carries id, adapter, parse() and pattern.

language.parse(input, options?)

Accepts a string, a SourceDocument, a SourceSlice or another parsed document. Handing it a slice is what makes a nested parse keep absolute offsets in the original file. Parses are cached per document, so re-parsing the same text with the same options is free.

Patterns: code

code`…`

One tag for both roles. As the first argument of a query it is a pattern and its holes are slots; as a replacement it is source and its holes are what the match captured. 

const call = code`console.log(${arg})`;

file.replaceAll(call, code`logger.debug(${arg})`);

A fragment compiles lazily, once per language it meets, cached on the template literal's own strings array — so a rule inside a loop pays for compilation once. code({ trivia: "ignore" })`…` sets per-fragment options.

Fragments compose: interpolating one into another splices its pattern in, captures and all.

A bare capture() in a list position binds a run, not a single node. To pin it to one, wrap it: exactly(1, name). This is the single most common surprise — code`f(${a}, ${b})` lets a take everything and leaves b empty.

Rewriting

MethodWhat it does
replace(query, to)the first match, like String.replace
replaceAll(query, to)every match, like String.replaceAll
remove(query) / removeAll(query)delete, taking the list separator with it
insertBefore(query, to) / insertAfter(query, to)insert, with the separation the list already shows

to is a code fragment, a string, an Edit, a list of edits, or a function from the match to any of those. Returning null leaves that match alone.

Nested matches. A pattern can match inside itself — {% if %} around another {% if %} — and both rewrites would want the same range. Matches arrive outermost first, so the outer one wins and the inner is left for a second pass. Matches whose edits do not collide are all kept, which is what lets a nested element be rewritten alongside the one containing it.

NodeRef

A parser node normalized to what the matcher needs. The parser's own node stays reachable through raw, fully typed.

MemberWhat it is
kindthe adapter's stable string for this node type
start, end, text(), slice()the absolute range in the root document
children, parent, isLeafthe tree
child(kind) / childrenOf(kind)the part of a construct you mean by name
trivianull, "whitespace", "comment" or "separator"
variadic, listSeparator, errorwhat the adapter declared about this kind

parsedthe parse this node belongs to

Searching a node searches the tree it is already part of and parses nothing. The node itself is never a match — only what it contains, exactly as a document never matches its own root. walk(node) is exported for a manual traversal.

match.replace`logger.debug(${arg})`                  // the whole match
match.replace(arg)`JSON.stringify(${arg})`           // one capture of it
match.insertBefore`// generated\n`
match.remove()                                       // or match.remove(handle)

Interpolating a handle inserts the exact source it bound in this match. Interpolating a handle the pattern never declared is a compile error.

A CaptureResult is a SourceSlice — text(), start, end, length, isEmpty(), position() — plus nodes, kinds(), and leading / trailing / full() for the trivia matching stepped over on either side.

Edits

Edit constructors return plain objects, so a rule is an ordinary function that returns an edit and a conditional rewrite is an if and a push. 

import { applyEdits, insertAfter, insertBefore, planEdits, remove, replace } from "@codestring/core";

replace(target, text)       // target: a node, a slice, a match or a capture result
remove(target)              // takes the adjacent list separator with it
insertBefore(target, text)  // with the separation the list already shows
insertAfter(target, text)

applyEdits(document, edits) // validated, then applied
planEdits(document, edits)  // the same validation, without applying

Guaranteed:

  • every byte outside an edit range is unchanged — no printer is involved anywhere
  • an interpolated slice keeps its exact source
  • edits from a nested match target the root document
  • an insert at the edge of a replaced range is allowed, in either listing order; several inserts at one position apply in the order given

Refused, loudly:

  • partially overlapping or nested edits — OverlappingEditError
  • one transform mixing two documents — SourceRevisionError
  • one capture handle in two positions of the same pattern — PatternCompileError
  • a repetition that could match nothing — PatternCompileError

@codestring/codemod

createTransformer(options)

OptionMeaning
language requiredwhat this transformer reads its files as
transform required({ file, source }) => a document, a string, or nothing to skip the file
nameshown in results; defaults to "<language> transform"
fileGlobone glob or several; omitted means every file it is handed
verify"parses", a predicate, or false. Defaults to "parses" when writing.

The returned Transformer has name, globs, transformers, appliesTo(path), transformString(), transformFile() and transformFiles().

createCodemod({ name, transformers })

Runs several transformers in order, each reading what the one before produced. It carries no language of its own, so one codemod can sweep several file types and each is read by whatever knows how to read it. It satisfies the same Transformer interface, so codemods nest.

FileResult

{ path, changed, before, after, written, applied }

applied names the transformers whose glob matched and which actually changed something, so a dry run (write: false) tells you what a real run would touch.

TransformVerificationError

Thrown when verify refuses a rewrite. Carries path and reason.

Also exported: collectFiles, matchesAnyGlob, readSource, writeSource.

@codestring/eslint

createRule(options)

Returns an ordinary Rule.RuleModule. See the tutorial for the full option table.

eslintLanguage(sourceCode)

A language backed by the AST ESLint already built. Exported so a hand-written visitor rule can still ask structural questions without parsing the file a second time.

Adapter extras

Adapters are mostly just an adapter object, but a few ship standalone accessors for things the normalized tree cannot express on its own. Each takes a node and nothing else.

@codestring/vue

isElement(node)does this node render a tag?
isComponent(node)does Vue resolve this tag through the component lookup?
tagOf(node)the written tag, or null
attributesOf(node)everything inside the start tag, in order
nameOf(node)class, or if for every spelling of v-if
contentOf(node)everything between the tags, tags excluded
vueNode(node)the compiler node, for what only @vue/compiler-dom knows

Kinds are element:<tag>, component:<tag>, directive:<name>, plus tag-open, tag-close, attributes, attribute, attribute-value, directive-argument, directive-argument-dynamic, expression, interpolation, text, comment, whitespace.

@codestring/babel

fromBabel(file, source)normalize an AST parsed elsewhere
babelLanguage(file, source, options?)a language answering the whole file from that AST
babelNode(node)the Babel node behind a matched one
babelIndex(root)every Babel node keyed to the matched node covering it

Together these let a codemod hold one tree: @babel/traverse for the scope chain, patterns for everything else, and both addressing the same node objects. 

const file = parse(source, { sourceType: "module", plugins: ["typescript"] });
const index = babelIndex(babelLanguage(file, source).parse(source).root);

index.get(someBabelNode)?.includes(code`this`);

@codestring/javascript

fromEstree(program, source, comments?) — normalize an ESTree program parsed elsewhere.

Errors

AdapterContractErroran adapter broke an invariant — bad range, children out of order, a child outside its parent
PatternCompileErrorthe pattern cannot be compiled — a handle used twice, a repetition that could match nothing
CaptureCardinalityErrorget() on a handle that did not bind
OverlappingEditErrortwo edits want overlapping ranges
SourceRevisionErrorone transform mixing edits from two documents
ParseErrorthe parse policy rejected a file with diagnostics
MatchErroran impossible match request — a pattern of another language against a node
